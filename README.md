# DATA 201 Database Design Project

This DATA 201 group project develops a relational database and data intelligence application using a selected dataset.

## Project Steps

1. Dataset ingestion
2. ER/EER diagram modeling
3. Logical relational schema design
4. Normalization to Third Normal Form (3NF)
5. Creation of MySQL tables
6. Implementation of primary keys, foreign keys, and constraints
7. Generation of interesting, domain-specific questions
8. Development of SQL analysis queries
9. Analysis of query results and insights
10. Development of an interactive dashboard
11. Creation of meaningful data visualizations
12. Preparation of the technical report
